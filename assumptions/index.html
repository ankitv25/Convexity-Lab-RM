A common axis is not a common methodology

Vanguard publishes nominal USD geometric return ranges. State Street reports arithmetic annual means in local or regional currency. The JPMorgan press release gives annual forecasts without independently specifying an aggregation convention there. These observations are not directly comparable; no currency conversion or arithmetic-to-geometric adjustment is applied.

Charts use one zero-anchored percent scale across all return observations, solely for display. A published range is not presented as a confidence band. No provider average or range midpoint is calculated.

Inference boundaries

Strategic estimates, not short-term trading signals

Read within the source

Return basis, currency, asset universe, horizon and publication date all affect interpretation. Differences between estimates cannot be attributed to provider conviction alone.

Keep uncertainty explicit

A point estimate does not describe the full distribution of outcomes. A published range does not establish a probability of returns falling within it. Missing observations remain missing.

Respect the horizon

These assumptions describe long-horizon expectations, not a near-term market path or guaranteed outcome. This research view does not translate estimates into investment instructions.
